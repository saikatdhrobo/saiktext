# SaikText

Modern text transformation workspace built with pure HTML, CSS, and JavaScript.

SaikText provides fast real-time text conversion, cleanup utilities, formatting tools, and live analytics inside a sleek modern UI.

---

## ✨ Features

### 🔤 Case Conversion

- UPPERCASE
- lowercase
- Title Case
- Sentence case
- aLtErNaTiNg
- camelCase
- PascalCase
- snake_case
- kebab-case
- CONSTANT_CASE

---

### 🛠 Text Utilities

- Remove extra spaces
- Remove duplicate lines
- Remove blank lines
- Reverse text
- Reverse word order
- Sort lines A-Z
- Shuffle text
- Undo / Redo support

---

### 📊 Live Analytics

- Character counter
- Word counter
- Sentence counter
- Paragraph counter

---

### 🎨 UI Features

- Modern glassmorphism interface
- Animated gradient background
- Floating preview card
- Responsive layout
- Keyboard shortcuts
- Smooth animations
- Toast notifications
- Custom cursor glow effect

---

## ⌨ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| Ctrl + Shift + U | Uppercase |
| Ctrl + Shift + L | Lowercase |
| Ctrl + Shift + C | Copy Output |
| Ctrl + Z | Undo |
| Ctrl + Y | Redo |
